## Git repo for instructions on how to set up your vm and with a basic geospatial env

### Rules and permissions
- This is a git tracked project the remote is https://github.com/jowa-ea/az_envs_setup.git
- You are allowed to create, edit, delete files and folders in this repo
- Start from SETUP_VM as an instructions file

### Objective
Build a repo to guide a new user into setting up an env in the azml VM.
Start with installing miniconda
Store some basic yml files with different env configs
Here build first yml conda file with the basic geospatial ml packages pandas, geopandas, numpy, rasterio, shapely, pyproj, pyarrow, psutil, sklearn, matplotlib and so on (suggest more of the standards)
This should be a clonable repo to quickly setup a new vm with instructions
